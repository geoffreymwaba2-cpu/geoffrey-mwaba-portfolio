# Geoffrey Mwaba — Portfolio

A responsive, single-page portfolio for Geoffrey Mwaba, an Information Technology student and aspiring front-end web developer in Zambia.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts when a network connection is available and includes system-font fallbacks.

## Publish with GitHub Pages

1. Create a public repository named `geoffrey-mwaba-portfolio` under `geoffreymwaba2-cpu`.
2. Add `index.html` and this README at the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Once the deployment completes, the portfolio will be available at `https://geoffreymwaba2-cpu.github.io/geoffrey-mwaba-portfolio/`.
